# Todo Reminder (DMS 插件)

DankMaterialShell 的待办清单小组件。

## 功能

- **快速勾选**：点击任务行或勾选圆钮即可标记完成；当日完成的任务显示删除线样式
- **添加任务**：输入文本回车即可添加；点击输入框旁的按钮展开选项，可选择
  - **日期**（YYYY-MM-DD，或一键"今天 / 明天"）
  - **时间**（HH:mm）
  - **每日循环**：任务每天重复出现，次日自动恢复为未完成
- **到点提醒**（可选，设置中开关）：带时间标记的任务到达时间时发送系统通知；
  优先使用 `dms notify`，回退 `notify-send`；错过超过 30 分钟的不再补发
- **跨天自动处理**：每日循环任务重置完成状态，非循环的已完成任务自动清理
- 逾期未完成的任务标记"已逾期"；一键"清除已完成"

## 数据

任务保存于 `~/.local/share/dms-todoReminder/todos.json`。
